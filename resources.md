This workshop is meant provides a gentle introduction to key
SQL concepts. If you've enjoyed this workshop and want to more
about SQL, I've found the following resources useful.

## A Note on SQL Dialects
While every SQL dialect has `SELECT`, `FROM`, `WHERE`, etc. clauses available, SQL dialects can differ in how
they implement certain text processing or date handling functions. When working with a real-world database,
make sure you know whether it's a SQLite, Postgres, or MySQL database. Each major "flavor" of SQL database
has a wealth of official documentation.

## Interactive Resources

* [PostgreSQL Exercises](https://pgexercises.com/)
This free set of interactive exercises allows you to practice writing progressively more complicated queries.

* [Become a SELECT *](https://wizardzines.com/zines/sql/) This tiny zine and SQL reference manual with
excellent diagrams includes an online SQL playground for practicing test queries. 

## Asynchronous Resources

* [Software Carpentries: SQL](https://swcarpentry.github.io/sql-novice-survey/aio.html) The model for this
workshop, this workshop has a few additional topics at the end that I cut for time when designing this
curriculum.

## Books

* [Database System Concepts (2020)](https://alliance-uoregon.primo.exlibrisgroup.com/permalink/01ALLIANCE_UO/uujmje/alma99901109062201852)
Available in PSC library, this textbook is used in many database courses. For most people, the first quarter
of the book is sufficient grounding in database theory. It also has [slide decks](https://db-book.com/) 
and practice exercises available on its official site.
