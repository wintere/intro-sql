# Introduction to SQL: Databases for Beginners
This repository stores the lesson notes for the University of Oregon Data Services workshop.

![](images/sql-logo.png)

## About
This interactive workshop teaches the fundamentals of using SQL (Structured Query Language) to extract and analyze data from relational databases.
Learn how to sort, filter, aggregation, and join data with SQL by writing your own queries!

No experience with SQL required, though participants may benefit from familiarity with programming languages like R or Python.
